# engenharia-requisitos-genai
Atividade de Engenharia de Requisitos UFG
1 - Utilizei o Copilot 365 para geração e analise das informações dispostas.

2 - Criei a persona de um engenheiro de requisitos e pedi para que ele analisasse as informações contidas no documento de Elicitação.

3 - A GenIA, fez a organização das informações identificando requisitos funcionais, Requisitos Não Funcionais, Regras de negocio e Dúvidas.

4 - Na sequencia pedi que me desse a recomendação dos melhores artefatos que foram:

ERS (Especificação de Requisitos de Software)
Diagrama de Casos de Uso
Descrição textual dos Casos de Uso
Documento de Regras de Negócio
Diagrama de Atividades dos fluxos críticos
Diagrama de Classes de Domínio
Protótipos de tela
Matriz de Rastreabilidade

5 - Das opções dadas, optei para que fossem gerados os artefatos abaixo, pois funcionam melhor em um projeto ágil:

ERS (Especificação de Requisitos de Software)
Descrição textual dos Casos de Uso 
Histórias de Usuário (Product Backlog)
Protótipos de tela
Matriz de Rastreabilidade

6 - Descartei os documentos abaixo, pois apesar de apoiar no esclarecimento, penso que muitos artefatos a serem validados também podem gerar retrabalho e nos anteriores já possuíam as informações importantes para um projeto ágil.

Diagrama de Casos de Uso
Diagrama de Atividades dos fluxos críticos
Diagrama de Classes de Domínio
