# Requisitos Funcionais

1. Requisitos Funcionais (RF)
RF01 – Consulta de eventos

O sistema deve permitir que os participantes visualizem todos os eventos disponíveis em um único local.

RF02 – Realização de inscrição

O sistema deve permitir que participantes realizem inscrições em eventos e workshops.

RF03 – Emissão de comprovante de inscrição

O sistema deve gerar e disponibilizar um comprovante de inscrição após sua realização.

RF04 – Cancelamento de inscrição

O sistema deve permitir que participantes cancelem suas inscrições, respeitando as regras definidas para cada evento.

RF05 – Acompanhamento de inscrições

O sistema deve permitir que participantes acompanhem o status de suas inscrições.

RF06 – Emissão de certificados

O sistema deve permitir a emissão de certificados para participantes após a realização do evento.

RF07 – Cadastro de eventos

O sistema deve permitir que organizadores criem e gerenciem eventos.

RF08 – Controle de vagas

O sistema deve controlar automaticamente a quantidade de vagas disponíveis em cada evento ou atividade.

RF09 – Lista de espera

O sistema deve permitir a criação e gerenciamento de listas de espera para eventos lotados.

RF10 – Monitoramento de inscrições

O sistema deve permitir que organizadores acompanhem a quantidade de inscritos em tempo real.

RF11 – Gerenciamento de participantes

O sistema deve permitir que organizadores consultem e gerenciem participantes inscritos.

RF12 – Gestão de pagamentos

O sistema deve registrar e controlar pagamentos relacionados às inscrições.

RF13 – Confirmação de pagamentos

O sistema deve permitir que a equipe financeira confirme pagamentos.

RF14 – Controle de reembolsos

O sistema deve permitir o registro e o controle de solicitações de reembolso.

RF15 – Consulta de programação

O sistema deve permitir que palestrantes consultem a programação dos eventos.

RF16 – Consulta de participantes pelos palestrantes

O sistema deve permitir que palestrantes visualizem os participantes inscritos em suas atividades.

RF17 – Envio de notificações

O sistema deve enviar comunicações relacionadas a inscrições, pagamentos, cancelamentos e certificados.
